# CNN-UNet

Glaucoma Detection using Deep Learning ( Convolution Neural Network - U-Net Based )



\# Glaucoma CDR Estimation using U-Net (Disc/Cup Segmentation)



This project performs \*\*optic disc\*\* and \*\*optic cup\*\* segmentation from retinal fundus images using a \*\*U-Net\*\* model, then estimates the \*\*Cup-to-Disc Ratio (CDR)\*\* from the predicted masks.



> Educational/research project only — not a clinical diagnostic tool.
