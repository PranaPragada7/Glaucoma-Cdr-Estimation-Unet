# Contributing

1. Create a branch from `main`.
2. Keep datasets and generated predictions outside version control.
3. Document the provenance and checksum of any replacement weights.
4. Add tests for preprocessing, tensor shapes, mask validation, and CDR behavior.
5. Run the validation commands in the README before opening a pull request.

Do not add diagnostic or clinical-performance claims without a reproducible,
appropriately governed evaluation dataset and clearly documented methodology.
