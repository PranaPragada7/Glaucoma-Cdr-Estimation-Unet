# Changelog

Notable changes to this project are documented here.

## 1.0.0 - 2026-08-19

- Reconstructed the U-Net architecture and verified the committed weights.
- Separated image loading, segmentation inference, mask validation, and CDR measurement.
- Added a command-line workflow that exports masks and a structured JSON summary.
- Added an explicit model card, research-only disclaimer, and reproducibility notes.
- Added behavioral tests, coverage enforcement, linting, and supported-version CI.
